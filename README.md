# Josric Pickle's Practical Course for Adventurers

A D&D 5e/2024 one-shot by Josef Pickett, built for a roughly three-hour session with 3–6 level-3 characters.

## 5eTools

Import:

`Josric_Pickle_Practical_Course_for_Adventurers_5etools.json`

The JSON references the maps in this repository through raw GitHub URLs, so the maps render when the homebrew is imported into 5eTools.

## Maps

- Base Library Room
- Book Mimic Room
- Book Puzzle Room
- Reinforced Door Room
- Librarian Room
- Teamwork Room
- Mirror Gallery
- Final Room
